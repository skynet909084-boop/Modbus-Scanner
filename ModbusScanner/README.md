# Modbus Scanner 1.1.0

См. [руководство](../README.md) и [изменения/ограничения](../CHANGELOG.md).

Порядок работы: выберите протокол и параметры, выполните поиск либо проверку связи, прочитайте диапазон. Имена/единицы/множитель/смещение задаются в таблице и сохраняются в профиле. Для сравнения сначала сделайте снимок, затем повторите чтение или включите мониторинг. Для графика введите до четырёх адресов через запятую. Историю и журнал сохраняйте до закрытия программы.

FC16 использует колонку «К записи FC16» для непрерывного диапазона от выбранной строки Holding Registers (максимум 123); проверяйте весь список в окне подтверждения. FC05/06 используют адрес и значение над таблицей. Запись нужно отдельно разрешить; мониторинг/поиск перед ней остановить.

Все адреса протокольные, от нуля. Устройство с корректным исключением обнаружено, но это не означает, что пробный регистр существует.
