# Modbus Scanner

**Modbus Scanner** — диагностическая программа для **Windows x64** для работы с промышленными устройствами по **Modbus RTU (RS-485 / COM)** и **Modbus TCP**.

**Разработчик / контакт:** Blood Sky · skynet909084@gmail.com

## Возможности

### Modbus RTU / TCP

- Подключение по **Modbus RTU** через COM / USB–RS-485 и по **Modbus TCP** через IP-адрес и порт.
- Чтение катушек, дискретных входов, holding и input registers (**FC01–FC04**).
- Запись катушки, одного или нескольких регистров (**FC05 / FC06 / FC16**) с явным разрешением, подтверждением и возможностью повторного чтения.
- Представление значений **DEC / HEX / BIN**, редактирование битов, поддержка 16- и 32-битных значений.
- Интерпретация **UInt16, Int16, UInt32, Int32, Float32** и порядок слов/байтов.
- Поиск Modbus-устройств и регистров, мониторинг, графики, снимки, журнал обмена и экспорт.
- JSON-карты регистров, профили и сохранение настроек.

### USB / RS-485 адаптеры (код v1.2.0)

- Обнаружение доступных **COM-портов Windows**.
- Приблизительное определение USB-преобразователей по **VID/PID**: **FTDI FT232/FT2232**, **WCH CH340/CH341**, **Silicon Labs CP210x**, **Prolific PL2303**.
- Выбор COM-порта из таблицы и переход в режим Modbus RTU.
- Экспорт TXT-отчёта с COM-портами, VID/PID и определёнными семействами адаптеров.
- **Важно:** программа **не содержит и не устанавливает драйверы USB**. Их устанавливает Windows либо пользователь из официального источника. Наличие COM-порта не гарантирует исправность линии A/B и ответа контроллера.

### Сеть и диагностика (код v1.2.0)

- IP-сканер с проверкой TCP-портов, обратным DNS и экспортом CSV.
- Выбор сетевого адаптера и ограничение диапазона сканирования.
- Логическая карта обнаруженных узлов с переходом к подключению Modbus TCP.
- Ping, мониторинг задержек и потерь, TCP-проверки, DNS, трассировка, сравнение шлюза и узла, анализ изменений ARP, TXT-отчёт.
- Встроенный локальный **Modbus TCP симулятор** для испытаний без физического оборудования.
- Интерфейс и справка на русском и английском.

> Карта сети показывает **логическую группировку**. Физическую топологию соединений коммутаторов программа не определяет.

## Быстрый старт

1. Для **RTU** подключите USB–RS-485 адаптер и убедитесь, что Windows создала COM-порт. В программе выберите RTU, COM, скорость, чётность, биты данных и стоп-биты.
2. Для **TCP** выберите TCP и укажите IP-адрес контроллера и порт (обычно **502**).
3. Укажите **Unit ID**, функцию и адрес регистра. Нажмите **«Подключить / проверить»**, затем прочитайте диапазон.
4. Перед записью проверьте документацию контроллера, адрес, тип значения и последствия изменения. Запись блокируется во время активного поиска или мониторинга.
5. Для проверки без оборудования используйте встроенный TCP-симулятор по адресу **127.0.0.1:1502**.

### Адресация Modbus

Программа использует **нулевые адреса протокола**. Например, обозначение holding register **40001** в документации часто соответствует функции **FC03** и адресу **0** в программе. У разных производителей встречаются исключения — сверяйтесь с руководством устройства.

## Сборка из исходников

Нужны **.NET 8 SDK** и среда с поддержкой **Windows WPF** (например, Windows + Visual Studio 2022).

```powershell
dotnet publish .\ModbusScanner\ModbusScanner.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```
